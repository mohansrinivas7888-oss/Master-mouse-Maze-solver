# Master-Mouse Hardware Pinout

| ESP32 Pin | Connected Component | Function / Protocol |
| :--- | :--- | :--- |
| `GPIO 21` | VL53L0X SDA | I2C Data |
| `GPIO 22` | VL53L0X SCL | I2C Clock |
| `GPIO 34` | Left IR Sensor | Analog ADC Input |
| `GPIO 35` | Right IR Sensor | Analog ADC Input |
| `GPIO 4` | TB6612FNG PWMA | Motor Left Speed (PWM) |
| `GPIO 16` | TB6612FNG AIN1 | Motor Left Direction |
| `GPIO 17` | TB6612FNG AIN2 | Motor Left Direction |
| `GPIO 18` | TB6612FNG PWMB | Motor Right Speed (PWM) |
| `GPIO 19` | TB6612FNG BIN1 | Motor Right Direction |
| `GPIO 23` | TB6612FNG BIN2 | Motor Right Direction |
